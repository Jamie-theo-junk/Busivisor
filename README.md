# IdeaProjects 💡

IdeaProjects is an Android application designed to help users **evaluate and rank their business ideas**. The app uses **Google Gemini AI** to analyze your ideas, provide recommendations, and rank them so you can quickly see which ideas have the most potential.  

It’s built with a modern architecture and provides a smooth user experience with a clean and intuitive interface.  

---

## 📱 Features

- Evaluate business ideas using AI (Google Gemini)  
- Receive recommendations to improve your ideas  
- Rank your ideas to identify the best ones  
- Three clear sections for structured evaluation  
- Ad integration for monetization  
- Clean, modern UI with intuitive navigation  

---

## 🛠 Built With

- Kotlin  
- Android Studio  
- Firebase (for data storage and user management)  
- Google Gemini (AI evaluation)  
- MVP Architecture (Model-View-Presenter)  
- Gradle

## 🚀 Getting Started

### Prerequisites

- Android Studio (latest stable version recommended)  
- Android SDK installed  
- Gradle (wrapper included in project)  

### Installation

1. Clone the repository  
2. Open the project in Android Studio  
3. Allow Gradle to sync  
4. Run the application on an emulator or physical device
